# TimeKeeper для DS-K1T341AM

Минимальный прототип учёта рабочего времени с веб-интерфейсом. Реализован на Flask + SQLite, поддерживает разграничение ролей (администратор / HR), добавление сотрудников на проекты, приём отметок из терминала DS-K1T341AM (через webhook или опрос) и оповещения в Telegram об опозданиях.

## Возможности
- Web-интерфейс для администратора и HR конкретного проекта.
- Добавление проектов, сотрудников (привязка `employeeCode` к терминалу) и пользователей системы.
- Учёт отметок прихода/ухода, фиксация опозданий с учётом часового пояса и грейса.
- Webhook `/api/hikvision/events` для приёма событий с терминала DS-K1T341AM.
- Заготовка клиента `HikvisionClient` для опроса ISAPI `alertStream` (безопасность: переменные окружения).
- Отправка уведомлений в Telegram при опоздании (переменные окружения `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
- Привязка Telegram-чата через polling-бота (`python -m app.telegram_bot`).
- Опциональная синхронизация Face ID (загрузка фото при добавлении сотрудника).

## Быстрый старт (локально / PyCharm)
1. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   export FLASK_APP=app.main
   flask run --reload --host 0.0.0.0 --port 8000
   ```
   По умолчанию база `timekeeper.db` создаётся в корне. Начальный пользователь: `admin` / `admin`.
3. Откройте `http://localhost:8000`.

## Подключение терминала DS-K1T341AM
- Настройте на стороне устройства отправку событий в `POST http(s)://<host>/api/hikvision/events` с JSON вида:
  ```json
  [{ "employeeCode": "123", "timestamp": "2024-06-01T09:10:00", "direction": "in" }]
  ```
- Для опроса по ISAPI задайте переменные `HIKVISION_HOST`, `HIKVISION_USER`, `HIKVISION_PASSWORD` и используйте `HikvisionClient.fetch_events()` (например, по расписанию cron) и `ingest_device_events` для записи в базу.
- Для синхронизации Face ID при создании сотрудника также нужны `HIKVISION_*` переменные.

## Настройка Telegram-оповещений
- Создайте бота и сохраните токен/чат:
  ```bash
  export TELEGRAM_BOT_TOKEN=<token>
  export TELEGRAM_CHAT_ID=<channel_or_chat_id>
  ```
- Либо запустите polling-бота и отправьте ему `/start`, чтобы чат сохранился в базе:
  ```bash
  python -m app.telegram_bot
  ```
- При первой отметке «вход» с опозданием функция `notify_late` отправит сообщение.

## Роли и доступы
- **Администратор**: создаёт проекты, пользователей, видит все проекты.
- **HR**: привязан к одному проекту, управляет сотрудниками и отметками только внутри него.

## Структура каталогов
- `app/main.py` — маршруты веб-интерфейса и API.
- `app/models.py` — модели SQLAlchemy (проекты, пользователи, сотрудники, отметки, события терминала).
- `app/time_service.py` — обработка событий, расчёт опозданий, уведомления.
- `app/hikvision.py` — простая обвязка для приёма/опроса DS-K1T341AM.
- `app/telegram_bot.py` — отправка сообщений в Telegram.
- `app/templates/` — HTML для основных экранов.

## Замечания по безопасности
- Смените `SECRET_KEY` в `app/__init__.py` и `app/main.py` перед выкладкой.
- Храните учётные данные терминала и Telegram-токен только в окружении/секретах.
- Добавьте обратный прокси и HTTPS для продакшена.
